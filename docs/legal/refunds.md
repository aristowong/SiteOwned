# Refunds

Draft – not legal advice, review with an attorney before launch.

Suggested defaults, editable before launch. The public page `/refunds/` currently uses these numbers:

- Done-for-you: full refund before work starts, half after the first draft and before launch, none after launch.
- Care plans: cancel anytime, no prorated refund of the current month.
- Course: 14-day refund if progress is under 30%. No refund of the call fee after the call happens.

Change the public page if you change these defaults.
